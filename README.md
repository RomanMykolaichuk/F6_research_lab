# F6 Research Lab

Методичний посібник для ад’юнктів кафедри інформаційно-аналітичних технологій НУОУ за спеціальністю F6 «Інформаційні системи і технології».

## Спринти

- [x] Спринт 0 — концепція та редакційний стандарт (погоджено).
- [x] Спринт 1 — нормативні та предметні засади.
- [x] Спринт 2 — методологія наукового дослідження.
- [x] Спринт 3 — наукові результати.
- [x] Спринт 4 — інструменти й експерименти.
- [x] Спринт 5 — наукова комунікація.
- [x] Спринт 6 — індивідуальна траєкторія ад’юнкта.
- [x] Спринт 7 — додатки.
- [x] Спринт 8 — [нормативні джерела](docs/sprint-7/regulatory-register.md) та [робота з ОНП](docs/sprint-7/onp-matrix.md).
- [ ] Спринт 9 — наукова прогалина й постановка кейсу А.
- [ ] Спринт 10 — відтворюваний експеримент і положення на захист.
- [ ] Спринт 11 — шкали оцінювання та зразки документів.
- [ ] Спринт 12 — кейси B–E та маршрути читача.
- [ ] Спринт 13 — повторне рецензування та видання.

**Статус:** навчально-методичний проєкт. Окремо позначаються норми права, текст ОНП та авторські рекомендації.
