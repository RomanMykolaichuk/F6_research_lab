# Розділ 2. Предметна область спеціальності F6

> **Тип тексту:** авторська методологічна інтерпретація стандарту МОН № 955, а не «паспорт спеціальності», затверджений органом влади.

## 2.1. Що вважати дослідницьким об'єктом у F6
Для дисертації потрібно встановити, який клас інформаційних систем, інформаційних процесів, технологій або організаційно-технологічних механізмів досліджується. Можливі об'єкти: процес інтеграції неоднорідних інформаційних ресурсів; функціонування інформаційно-аналітичних систем; процес оброблення і розподілу потоків даних; процес прийняття рішень із застосуванням інформаційної системи; процес адаптивного управління інформаційними сервісами. Прикладна сфера (освіта, оборона, охорона здоров'я) характеризує умови дослідження, але не є достатнім визначенням об'єкта спеціальності.

**Предмет** має виділяти властивість або спосіб змінення функціонування об'єкта: моделі, методи, критерії, принципи, технології або процедури оцінювання, синтезу, адаптації, інтеграції, забезпечення якості. Не варто формулювати предмет як «застосування Python» або «використання нейромережі»: це інструмент, а не наукова характеристика.

## 2.2. Від наукової задачі до внеску в інформаційні системи
Три рівні аргументації:
1. **Потреба:** у конкретному класі систем є вимірюване обмеження (затримка, неповнота, витрати, нестійкість, похибка, непрозорість).
2. **Прогалина:** наявні методи за визначених припущень не забезпечують бажаного співвідношення показників; твердження підтверджене літературою і базовими експериментами.
3. **Внесок:** запропоновано нову/удосконалену модель, метод або інформаційну технологію, відмінності формалізовано і підтверджено належним дослідженням.

Військова актуальність може бути високою, але без третього рівня технічна дисертація ризикує перетворитися на рекомендації з організації діяльності. І навпаки, нетривіальний метод інтеграції або оцінювання інформаційної системи може мати наукову цінність незалежно від того, чи апробований він у навчальному або іншому контексті.

## 2.3. Орієнтовні тематичні напрями кафедри
Це **робоча карта**, не офіційний нормативний перелік:
- Моделювання та оптимізація інформаційно-аналітичних процесів.
- Архітектура інтелектуальних інформаційних систем.
- Інтеграція різнорідних даних, семантична інтероперабельність.
- Управління якістю, надійністю та ефективністю ІСТ.
- Багатокритеріальне оцінювання альтернатив на технологічному рівні.
- Автоматизоване управління інформаційними й обчислювальними ресурсами.
- Графи знань та інформаційні технології адаптивного навчання.
- Мультиагентна оркестрація компонентів ІСТ.
- Методи перевірки, моніторингу й оцінювання результатів застосування ШІ в ІСТ.

## 2.4. Межі із суміжними спеціальностями
| Прикордонна ситуація | Можливий акцент F6 | Питання для відмежування |
|---|---|---|
| Нова математична оптимізація | Інтеграція в процеси й архітектуру ІСТ | У чому саме новизна для інформаційної системи? |
| Нова ML-архітектура | Спосіб адаптації / оркестрації системи | Чи не зводиться дослідження до самої моделі ML? |
| Розробка програмного забезпечення | Метод функціонування чи розвитку ІСТ | Чи є новий результат за межами програмної реалізації? |
| Кіберзахист | Надійність і якість процесів ІСТ | Чи центральна наукова задача саме про безпеку? |
| Військова аналітика | ІА процеси, моделі й методи систем | Чи формулюється результат незалежно від тактичного сценарію? |
| Педагогіка | Інформаційна технологія адаптивної системи | Чи досліджується саме педагогічний ефект чи механізм ІСТ? |

**Правило:** остаточна належність теми визначається сукупністю об'єкта, предмета, сформульованої новизни, методів і результатів, а не лише ключовими словами назви.

## 2.5. Приклади трансформації теми
**Надто прикладне формулювання:** «Підвищення ефективності роботи аналітиків з використанням ШІ».
**Уточнення F6:** «Метод багатокритеріального оцінювання ефективності розподілу ШІ-сервісів між інформаційно-аналітичними завданнями».
**Науковий зміст:** формальна постановка задачі розподілу, система показників, обмеження, алгоритм оцінювання, порівняння з базовими методами.

**Надто програмне формулювання:** «Створення вебзастосунку для навчання за графом знань».
**Уточнення F6:** «Інформаційна технологія адаптивного формування навчальних ситуацій на основі стану засвоєння графа знань».
**Науковий зміст:** модель знань і стану, правило адаптації, критерії ефективності, контрольний експеримент.

## 2.6. Формуляр предметної рамки дисертації
| Поле | Що записати |
|---|---|
| Клас ІСТ | Тип системи, масштаби, межі |
| Процес | Вхід, перетворення, вихід |
| Наукове протиріччя | Що не вдається досягти одночасно? |
| Наявні підходи | 3–5 найближчих аналогів |
| Об'єкт | Процес/система, що досліджується |
| Предмет | Конкретні моделі, методи, властивості |
| Змінні | Вхідні, керовані, випадкові |
| Показники | Якість, час, ресурси, стійкість |
| Результат | Новий/удосконалений артефакт знання |
| Перевірка | Метод, baseline, дані, критерій успіху |

## Контрольне запитання
Як сформулювати науковий результат так, щоб він залишався внеском у F6 після заміни військового прикладу на цивільний? Якщо результат повністю зникає, необхідно ще раз перевірити предмет дослідження.
