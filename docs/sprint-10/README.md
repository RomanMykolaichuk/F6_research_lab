# Спринт 10. Відтворюваний експеримент кейсу A

Статус: навчальний протокол і реалізація; контрольний запуск та його середовище задокументовано у [протоколі відтворення](../sprint-13/case-a-results.md).

## Запуск
Python 3.11, створити віртуальне середовище, встановити залежності:
```sh
pip install -r requirements.txt
python experiment.py > results.json
```

## Дизайн
300 незалежних навчальних сценаріїв, 120 тестових IID та 120 зі зміщенням контексту. Seed 101/202/303; bootstrap 404. Вісім альтернатив у сценарії. Критерії вже нормовані генератором. Жорсткий фільтр перед ранжуванням. Сценарії з менш ніж двома допустимими альтернативами виключені з парної метрики; це не оцінка всіх випадків застосування.

B0 — логістична модель різниць критеріїв; B1 — контекстні лінійні ваги; MLP — попарний класифікатор із контекстом; абляція — MLP без контексту. Попарні ймовірності агрегуються середнім балом, тому це наближення до Uθ, а не доведена скалярна функція корисності. Оракул синтетичний, має нелінійну взаємодію; це сприятливе припущення для нелінійних моделей, а не нейтральна перевірка реальної переваги.

Метрики: середня сценарна точність, regret, порушення обмежень; парний bootstrap різниці точності MLP–B1. H1: нижня межа інтервалу має перевищити 0.05 для заяви про мінімальний ефект. H2: оцінити окремо shift. H3: фільтрація гарантує допустимість лише за коректних вхідних показників. B2 з літератури не відтворено.

## Межі
Не заявляти наукової новизни, реальної ефективності або переваги RL. Для повної перевірки потрібні лінійний і альтернативні нелінійні оракули, незалежні експертні мітки, перевірка порожньої множини, повтори навчання, час inference, пряме порівняння з найближчими аналогами. Не підбирати параметри за тестом.
