# Від експерименту до положень на захист

| Кандидат | Доказ | Межа |
|---|---|---|
| Модель контекстного оцінювання | Формалізація, порівняння з найближчими аналогами | Попарний класифікатор не гарантує транзитивності |
| Метод добору допустимих альтернатив | Перевірка фільтра, граничних випадків, абляція | Відомий фільтр сам по собі не новизна |
| Емпірична властивість | Парний ефект, інтервал, незалежні сценарії | Лише синтетичний клас задач |

Шаблон: запропоновано [механізм], який відрізняється від [конкретний аналог] за [ознакою]; у [умовах] встановлено [ефект та невизначеність]. Заповнювати лише після отримання доказів. Якщо інтервал не підтверджує гіпотезу, описати негативний результат, не змінювати поріг постфактум.
