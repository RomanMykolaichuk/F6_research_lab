# Кейс B. Динамічне управління ресурсами ІСТ

Навчальний проєкт, не підтверджена наукова новизна.

## Постановка
Дані: Черга завдань цивільного сервісу, доступні обчислення, випадкові надходження.
Тип результату: Модель MDP.
Кандидатна гіпотеза: Чи покращує адаптація компроміс між чергою та витратами за змінного навантаження?
Прогалина потребує перевірки: знайти найближчі аналоги, заповнити [матрицю](../sprint-7/analogue-matrix.md), встановити відмінність і контрприклад.

## Формалізація
s=(q,c), a — число виділених обчислювальних слотів від 0 до c; q'=max(0,q-a)+ arrivals; c' задається незалежним генератором; r=-q'-0.2a. Горизонт 100 кроків, γ=0.95.

## Ручний приклад
За q=5,c=3,a=2, arrivals=1: q'=4, r=-4.4. Це перевірка переходу, не доказ ефективності.

## Протокол
Baseline: Фіксоване виділення, greedy, табличне Q-learning.
Метрики: Середня черга, витрати, частка порушень місткості; незалежні траєкторії.
До запуску зафіксувати мінімальний ефект, незалежні одиниці, seed, розподіл train/validation/test (де є навчання), інтервали невизначеності. Зберегти сирі дані, код, версії, SHA. Не змінювати критерій успіху після тесту.

## Загрози валідності
Перевірити Markov-властивість; якщо надходження корельовані, розширити стан. Не ототожнювати модель із методом RL.
