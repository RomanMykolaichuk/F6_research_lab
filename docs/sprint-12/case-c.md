# Кейс C. Адаптивний граф знань

Навчальний проєкт, не підтверджена наукова новизна.

## Постановка
Дані: Синтетичні профілі засвоєння і граф передумов навчання.
Тип результату: Інформаційна технологія.
Кандидатна гіпотеза: Чи зменшує адаптивний добір кількість недоречних рекомендацій за однакового графа?
Прогалина потребує перевірки: знайти найближчі аналоги, заповнити [матрицю](../sprint-7/analogue-matrix.md), встановити відмінність і контрприклад.

## Формалізація
G=(V,E), p_v∈[0,1]; доступний вузол має всі передумови з p≥0.8; обирати доступний вузол з мінімальним p, якщо p<0.8; при порожній множині — завершення або діагностика циклу.

## Ручний приклад
A→B→C, p=(.9,.4,.1): обираємо B, C заблоковано. Для (.9,.9,.1) обираємо C.

## Протокол
Baseline: Фіксована послідовність, випадковий доступний вузол.
Метрики: Покриття, порушення передумов, стабільність, число кроків; окремо якість генерації.
До запуску зафіксувати мінімальний ефект, незалежні одиниці, seed, розподіл train/validation/test (де є навчання), інтервали невизначеності. Зберегти сирі дані, код, версії, SHA. Не змінювати критерій успіху після тесту.

## Загрози валідності
Симуляція не доводить навчального ефекту. Реальні учасники потребують етичного погодження; перевірити цикли, помилки діагностики та якість матеріалів.
