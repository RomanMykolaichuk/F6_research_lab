## Технічна перевірка видання

Обидва формати зібрано з одного рукопису. Перевірено 24 основні розділи, 192 локальні посилання в Markdown і наявність змісту та закладок у PDF. Повторний запуск команди, витягнутої з PDF, у контрольному середовищі дав побайтово ідентичний results.json. Під час навчання scikit-learn повідомив про досягнення ліміту 400 ітерацій до збіжності. Результати описують модель після заданого бюджету навчання. Для оцінювання стійкості потрібен окремий експеримент із наперед визначеними бюджетами.

Для повторного складання потрібні Python із python-docx, Pandoc та LibreOffice Writer. З кореня репозиторію виконайте `python docs/sprint-13/build.py`. Переносні файли для читання містять друковані форми; машинозчитувані CSV, скрипти і контрольний JSON доступні за посиланнями з тексту.
