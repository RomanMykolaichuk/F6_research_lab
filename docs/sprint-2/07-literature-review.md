# 7. Аналіз стану наукових досліджень

## 7.1. Протокол пошуку
До пошуку зафіксуйте питання, бази, терміни, часові межі та критерії відбору. Використовуйте IEEE Xplore, ACM DL, Scopus, Web of Science або інші доступні джерела; Google Scholar допомагає знаходити додаткові матеріали. Не обмежуйте огляд лише останніми роками, якщо фундаментальні методи старші.

## 7.2. Відбір
Збережіть експорт метаданих, видаліть дублікати за DOI та назвою, відберіть за анотаціями, перевірте повні тексти. Фіксуйте причини виключення на етапі повного тексту. Для систематичного огляду застосовуйте релевантні настанови звітування, зокрема PRISMA 2020, не підміняючи ними оцінювання якості.

## 7.3. Матриця порівняння
| Поле | Зміст |
|---|---|
| Ідентифікатор | DOI, автори, рік |
| Задача | Що саме розв'язано |
| Метод | Модель, алгоритм, припущення |
| Дані | Походження, обсяг, доступність |
| Порівняння | Baseline та умови |
| Результат | Метрики, невизначеність |
| Обмеження | Заявлені та виявлені окремо |
| Релевантність | Зв'язок із власною задачею |

Не порівнюйте числові метрики різних статей без перевірки сумісності наборів даних і протоколів.

## 7.4. Синтез
Групуйте праці за механізмом розв'язання задачі, а не за роками. Для кожної групи встановіть сильні сторони, припущення, обмеження та умови застосування. Найближчий аналог визначається подібністю наукової задачі та механізму, а не лише назвою.

## 7.5. ШІ в огляді
ШІ може запропонувати синоніми, допомогти структурувати матрицю або пояснити термін. Кожне бібліографічне посилання, цитату та числовий результат перевіряйте за першоджерелом. Не завантажуйте матеріали обмеженого доступу в зовнішні сервіси.

## Практикум
Створіть журнал пошуку, матрицю десяти найближчих робіт та синтез із трьох абзаців: відоме, невирішене, обґрунтована задача. Десять робіт — навчальний старт, а не нормативний мінімум.
