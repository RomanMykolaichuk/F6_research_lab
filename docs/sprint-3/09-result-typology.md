# 9. Типологія наукових результатів

Науковий результат — обґрунтоване нове знання, отримане внаслідок дослідження. Артефакт реалізації, публікація та акт впровадження можуть підтверджувати окремі аспекти результату, але не замінюють його змісту.

| Тип | На яке питання відповідає | Необхідний опис | Доказ |
|---|---|---|---|
| Наукове положення | Яка закономірність встановлена? | Умови, твердження, межі | Доведення або емпіричні дані |
| Принцип | Яке правило організації обґрунтовано? | Зміст, сфера застосування | Аргументація, порівняння |
| Концепція | Як організовано систему ідей? | Поняття, зв'язки, принципи | Логічна узгодженість, застосовність |
| Модель | Як представити об'єкт? | Змінні, відношення, припущення | Верифікація, валідація |
| Метод | Як розв'язати клас задач? | Вхід, механізм, вихід, умови | Аналіз властивостей, експеримент |
| Алгоритм | Якою послідовністю виконати обчислення? | Кроки, завершення, складність | Коректність, тести |
| Методика | Як організувати комплекс процедур для визначеної мети? | Етапи, методи, правила, критерії | Повторюваність, порівняння |
| Інформаційна технологія | Як організувати взаємопов'язані інформаційні процеси? | Дані, методи, архітектура, взаємодія | Інтеграційні тести, оцінка системи |

Термінологія різних наукових шкіл може відрізнятися. Не встановлюємо штучної ієрархії: модель може бути самостійним результатом, алгоритм — новим науковим внеском, а технологія — комплексом відомих компонентів без доведеної новизни.

## Приклад
У системі адаптивного навчання граф знань є представленням предметної області; модель стану засвоєння описує оцінки знань; метод добору визначає наступну навчальну ситуацію; алгоритм реалізує добір; інформаційна технологія поєднує діагностику, добір, генерацію, перевірку й оновлення стану. Новизну кожного заявленого результату необхідно довести окремо.

## Практикум
Класифікуйте три очікувані результати власної дисертації. Для кожного назвіть найближчий аналог, відмінність і доказ. Якщо опис складається лише з переліку бібліотек, поверніться до наукової задачі.
