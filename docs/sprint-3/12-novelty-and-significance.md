# 12. Наукова новизна та практичне значення

## 12.1. Структура твердження
Робоча формула: тип результату + зміст + відмінність від найближчого аналога + обґрунтована властивість + умови застосування. Слова «вперше», «удосконалено», «набув подальшого розвитку» не є доказом. Їх застосування залежить від змісту та результатів огляду, а не від бажаної кількості положень.

## 12.2. Приклади редагування
Слабко: «Вперше застосовано нейронну мережу для оцінювання». Кандидатне уточнення: «Запропоновано модель контекстно-залежного агрегування критеріїв, що відрізняється від фіксованої вагової суми механізмом зміни переваг залежно від стану системи». Далі потрібно перевірити аналоги, властивості й емпіричний ефект; сам текст не встановлює пріоритету.

Слабко: «Розроблено вебзастосунок на FastAPI». Уточнення: «Запропоновано інформаційну технологію адаптивного добору матеріалів, у якій стан графа знань визначає правила формування наступної ситуації». Необхідно довести відмінність від існуючих адаптивних систем.

**Ред-тім приклад:** для кейсу A зміна формулювання v0 → v0.2 під впливом опублікованих аналогів розібрана в [карті наукової прогалини](../sprint-9/case-a-gap.md). До фактичної перевірки не використовуйте «вперше» і не перетворюйте відмінність предметної області на доказ новизни.

## 12.3. Матриця доказів
| Твердження | Необхідний доказ |
|---|---|
| Метод коректний | Доведення або обґрунтована перевірка у визначеній області |
| Метод точніший | Контрольне порівняння, оцінка невизначеності |
| Метод швидший | Однакові умови вимірювання, аналіз витрат |
| Компонент забезпечує ефект | Абляція або контроль альтернативних пояснень |
| Технологія придатна для застосування | Валідація у заявлених умовах |
| Результат новий | Порівняння з найближчими науковими аналогами |

## 12.4. Практичне значення
Визначте користувача, процес, умови, вимірювану користь та витрати впровадження. Розрізняйте потенційну користь, експериментально встановлений ефект і документоване впровадження. Акт впровадження не підтверджує автоматично наукову новизну.

## 12.5. Саморецензування
Чи існує аналог з таким самим механізмом? Чи зберігається внесок після заміни бібліотеки? Чи справедливий висновок за інших параметрів? Чи відповідає доказ силі твердження? Чи можна незалежно повторити перевірку? Якщо відповідь невідома, позначте це як дослідницьку задачу, а не приховуйте обмеження.

Практикум: сформулюйте три кандидатні положення, для кожного заповніть паспорт результату. Після огляду та експериментів перегляньте формулювання.
