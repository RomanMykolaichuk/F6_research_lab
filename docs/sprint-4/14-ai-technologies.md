# 14. Штучний інтелект у дослідженнях F6

| Технологія | Доцільне питання | Типова перевірка |
|---|---|---|
| Класичне ML | Прогноз чи класифікація | Незалежний тест, простий baseline |
| Глибоке навчання | Складні представлення | Абляція, витрати, узагальнення |
| RL | Послідовні рішення в середовищі | Евристики, незалежні сценарії, кілька seed |
| LLM | Оброблення або генерація тексту | Фактичність, стабільність, вартість |
| RAG | Відповіді з джерелами | Якість пошуку та відповіді окремо |
| Графи знань | Семантичні зв'язки | Еталонні факти, повнота |
| Мультиагентні системи | Координація компонентів | Порівняння з одним агентом, накладні витрати |

## Вибір методу
Починайте з найпростішого придатного рішення. Для табличних даних складна нейромережа не обов'язково краща за регресію чи дерева. Для RL перевірте, чи задача справді послідовна, чи доступне валідоване середовище і чи винагорода відображає ціль. Для RAG відокремлюйте помилки пошуку від помилок генерації.

## Оцінювання
Розділяйте дані на навчальні, валідаційні та тестові; за часової залежності використовуйте хронологічне розділення. Не налаштовуйте модель на тестовому наборі. Для LLM фіксуйте версію моделі, промпти, параметри генерації, корпус і дату запуску. Автоматичний оцінювач не є безпомилковим еталоном; перевіряйте його на незалежній розміченій вибірці.

Практикум: обґрунтуйте вибір технології та двох базових альтернатив. Визначте умови, за яких відмовитеся від складнішого методу.
