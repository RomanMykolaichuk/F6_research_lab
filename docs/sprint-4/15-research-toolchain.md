# 15. Інструментальне середовище ад'юнкта

Рекомендований стек є змінюваним, а не обов'язковим: Python, Jupyter, NumPy, pandas, scikit-learn, TensorFlow/PyTorch, Gymnasium, PostgreSQL, FastAPI, Git, Docker, Plotly/Chart.js, локальні LLM через Ollama.

## Структура репозиторію
- src/ — реалізація методів;
- tests/ — модульні й інтеграційні тести;
- configs/ — параметри запуску;
- data/README.md — походження та доступ;
- experiments/ — сценарії та протоколи;
- results/ — машинозчитувані результати;
- notebooks/ — дослідницький аналіз;
- README.md — інструкція відтворення.

Фіксуйте версії залежностей, ОС, апаратне середовище, seed, commit SHA та конфігурацію. Seed не гарантує повної детермінованості на всіх пристроях. Ноутбук має виконуватися від початку до кінця без прихованого стану. Зберігайте необроблені результати окремо від графіків.

## База даних
Для журналу експериментів доцільно мати таблиці runs, configurations, metrics. Ключ запуску пов'язує параметри й вимірювання. Використовуйте параметризовані SQL-запити та обмеження цілісності. Не зберігайте паролі в коді.

Практикум: підготуйте README з командами встановлення, тестування та відтворення одного експерименту.
