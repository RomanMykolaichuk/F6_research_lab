# 17. Оцінювання ефективності інформаційних технологій

Ефективність визначається відносно цілі, умов і витрат. Розрізняйте результативність (досягнення цілі), ресурсну ефективність та якість. Не зводьте різні виміри до одного числа без обґрунтування.

## Критерії
Для класифікації: precision, recall, F1, калібрування; для системи: затримка, пропускна здатність, доступність, витрати. Вибір залежить від задачі. Середня затримка може приховувати довгий хвіст, тому доречні квантилі.

## Багатокритеріальне оцінювання
Для показника користі z=(x-L)/(U-L), для витрат z=(U-x)/(U-L), якщо U>L. Межі визначаються до порівняння; вихід за них потребує явного правила. За U=L нормалізація не визначена. Лінійна сума S=Σw_j z_j, w_j≥0, Σw_j=1, передбачає компенсаторність. Критичні обмеження краще задавати окремо. Парето-фронт показує недоміновані альтернативи, але не визначає єдину перевагу.

## Експертні оцінки
Документуйте добір експертів, шкалу, процедуру, розбіжності та конфлікти інтересів. Узгодженість не гарантує істинності. Для навченої функції агрегування потрібні незалежні еталонні переваги й перевірка поза навчальною вибіркою.
