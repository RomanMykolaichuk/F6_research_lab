# 18. Візуалізація та інтерпретація результатів

| Питання | Подання |
|---|---|
| Як розподілені вимірювання? | Гістограма, ECDF, boxplot |
| Як змінюється показник? | Лінійний графік |
| Як відрізняються методи? | Парні точки, оцінка ефекту та інтервал |
| Який компроміс між критеріями? | Scatter plot, Парето-фронт |
| Як взаємодіють компоненти? | Граф або схема потоків |

Позначайте одиниці, обсяг вибірки, зміст інтервалів, умови експерименту. Не обрізайте осі стовпчикових графіків так, щоб перебільшувати відмінності. Не використовуйте колір як єдиний спосіб кодування.

Дискусія пояснює механізм, альтернативні інтерпретації та межі результату. Висновок має відповідати фактичному дизайну: синтетичний експеримент не доводить ефективності реальної експлуатації. Публікуйте лише дозволені дані та агрегати, які не розкривають захищеної інформації.

Практикум: створіть графік, таблицю первинних показників і абзац інтерпретації з одним обмеженням.
