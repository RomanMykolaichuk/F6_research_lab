# 19. Підготовка наукових публікацій

## 19.1. Публікація як доказова ланка
Стаття має відповідати на конкретне наукове питання. Не плануйте публікації лише за кількістю: побудуйте матрицю «задача дисертації — результат — доказ — публікація». Уникайте штучного дроблення одного результату на мінімальні фрагменти та повторного подання того самого тексту без належного розкриття.

## 19.2. Типологія статей
| Тип | Центральний зміст | Доказова основа |
|---|---|---|
| Оглядова | Синтез стану досліджень | Прозорий протокол пошуку та відбору |
| Методологічна | Обґрунтування дослідницького підходу | Логіка, порівняння, межі |
| Теоретична | Модель або властивість | Формалізація, доведення, контрприклади |
| Конструктивна | Метод або інформаційна технологія | Опис артефакту, оцінювання |
| Експериментальна | Перевірка гіпотези | Контрольний дизайн, дані, аналіз |

Ця класифікація методична, а не перелік нормативно визначених видів публікацій.

## 19.3. IMRaD
Introduction: проблема, стан знань, прогалина, питання та внесок. Methods: дані, припущення, реалізація, baseline, метрики, протокол. Results: фактичні результати з невизначеністю, включно з негативними. Discussion: механізми, альтернативні пояснення, зіставлення з літературою, обмеження. Conclusion: відповідь на питання без нових непідтверджених тверджень. Для теоретичних робіт структура може відрізнятися відповідно до правил журналу.

Анотація має стисло передавати проблему, мету, метод, отримані результати й висновок. Не вигадуйте числових результатів для незавершеного експерименту. Назва повинна відображати предмет і внесок, а не обіцяти доведену перевагу до перевірки.

## 19.4. Вибір видання
Перевірте тематичну відповідність, правила авторства, рецензування, індексацію за офіційними реєстрами, архів, платежі та політику даних. Наявність DOI або логотипу Scopus не доводить індексації. Вимоги до зарахування публікацій для атестації звіряйте з чинним порядком присудження ступеня та локальними документами.

## 19.5. Рецензування
Відповідайте на кожне зауваження окремо: цитата зауваження, відповідь, конкретна зміна, місце в рукописі. Якщо не погоджуєтеся, обґрунтуйте це доказами. Не заявляйте про виконані експерименти, яких не було.

## 19.6. Наскрізна публікаційна стратегія
A — критерії та модель оцінювання ШІ, метод агрегування, незалежна перевірка. B — модель середовища, метод розподілу обчислень, порівняльний експеримент. C — модель графа знань, технологія адаптації, оцінювання. D — семантична модель, метод зіставлення, експеримент. E — модель невизначеності, метод ранжування, аналіз стійкості. Це можливі лінії роботи, а не обов'язкова кількість статей.

Практикум: складіть карту публікацій із залежностями, готовністю доказів і кандидатними виданнями.
