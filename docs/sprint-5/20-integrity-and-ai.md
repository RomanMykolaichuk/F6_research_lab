# 20. Академічна доброчесність та використання ШІ

## 20.1. Відповідальність дослідника
Автор відповідає за достовірність тексту, даних, цитувань, коду та висновків. Фабрикація — вигадування даних; фальсифікація — неправомірне спотворення; плагіат — привласнення чужих результатів або тексту. Повторне використання власних матеріалів потребує прозорого цитування та дотримання правил видання й законодавства. Конкретні юридичні визначення та процедури перевіряйте за чинними актами.

## 20.2. Використання генеративного ШІ
| Дія | Контроль |
|---|---|
| Мовне редагування | Перевірка збереження змісту |
| Пошукові терміни | Самостійний пошук першоджерел |
| Генерація коду | Рев'ю, тести, перевірка ліцензій |
| Пояснення формул | Незалежне виведення та перевірка |
| Аналіз даних | Відтворюваний код, контроль припущень |
| Чернетка тексту | Перевірка фактів, авторська аргументація, розкриття використання |

ШІ не є автором, здатним нести відповідальність за дослідження. Не використовуйте вигадані джерела, синтетичні відповіді як реальні спостереження або неперевірені висновки. Дотримуйтеся політики конкретного журналу та університету; дозволеність одного способу використання не означає дозволеність усіх.

## 20.3. Перевірка джерел
Для кожного посилання перевірте авторів, назву, рік, DOI, повний текст і відповідність твердженню. Не цитуйте джерело лише тому, що його запропонувала модель. Фіксуйте виправлення, відкликання та версії препринтів.

## 20.4. Дослідницька етика
Дослідження за участю людей потребує належної етичної оцінки, інформування, добровільності та захисту персональних даних відповідно до застосовних процедур. Для навчальних експериментів враховуйте залежність студента від викладача. Синтетичні профілі не замінюють доказів щодо реальних людей.

## 20.5. Інформаційна безпека
Перед передаванням матеріалів у зовнішній ШІ-сервіс перевірте режим доступу та дозволеність оброблення. Не передавайте захищені документи, персональні дані чи службові метадані без належних підстав. Публічний GitHub використовуйте лише для дозволених матеріалів.

## 20.6. Декларація
Фіксуйте інструмент, версію, мету використання, тип матеріалів, спосіб перевірки та внесок автора. Не покладайтеся на детектор ШІ як на самодостатній доказ порушення.

Практикум: заповніть журнал використання ШІ для одного дослідницького завдання та перевірте всі запропоновані джерела.
