# Глосарій UA–EN
Робочі відповідники, не офіційний термінологічний стандарт.

| Українською | English | Зміст |
|---|---|---|
| Наукова прогалина | Research gap | Обґрунтоване обмеження наявних знань |
| Наукова задача | Research problem | Питання, що потребує нового знання |
| Гіпотеза | Hypothesis | Перевірюване припущення |
| Науковий внесок | Research contribution | Обґрунтоване доповнення знань |
| Модель | Model | Представлення об'єкта для визначеної мети |
| Метод | Method | Спосіб розв'язання класу задач |
| Методика | Methodology / procedure | Організований комплекс процедур; переклад залежить від контексту |
| Алгоритм | Algorithm | Визначена послідовність обчислювальних дій |
| Артефакт | Artifact | Створений об'єкт дослідження |
| Верифікація | Verification | Перевірка відповідності специфікації |
| Валідація | Validation | Перевірка придатності для мети |
| Базовий метод | Baseline | Метод порівняння |
| Абляція | Ablation study | Оцінка внеску компонентів |
| Чутливість | Sensitivity | Залежність результату від параметрів |
| Розмір ефекту | Effect size | Величина відмінності |
| Відтворюваність | Reproducibility | Можливість повторного отримання результату за описаною процедурою; визначення залежить від стандарту |
| Простежуваність | Traceability | Зв'язок вимог, результатів і доказів |
| Загроза валідності | Threat to validity | Фактор, що обмежує обґрунтованість висновку |
| Наукова доброчесність | Research integrity | Принципи відповідального дослідження |
