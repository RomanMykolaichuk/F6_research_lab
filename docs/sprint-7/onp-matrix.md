# Від програмного результату до матеріалу дисертації

## Приклад для навчання

У [проєкті ОНП 2025 року](https://nuou.org.ua/assets/documents/onp-f6-ist-25.pdf), розділ 7, с. 14, ПРН03 стосується формулювання та перевірки гіпотез і добору доказів для висновків. Це джерело прикладу. Для індивідуального плану перенесіть код і повний текст результату із затвердженої редакції свого набору. Реквізити документа 2025 року наведено у [реєстрі, N05](regulatory-register.md).

| Що заповнюємо | Зразок запису ад’юнкта |
|---|---|
| Результат, який відпрацьовую | ПРН03 у навчальному прикладі. Перевірка гіпотези про час пошуку в архіві документів. |
| Навчальний план | Обираю компонент з експериментальних методів. Точну назву та код звіряю зі своїм планом. |
| Індивідуальний план наукової роботи | До кінця другого семестру порівняти два способи пошуку на тих самих запитах. Заздалегідь визначити метрику часу й мінімально прийнятну повноту пошуку. |
| Результат для дисертації | У розділ про експеримент включити протокол, таблицю парних вимірювань та пояснення, за яких умов зміна часу сумісна зі збереженням повноти. |
| Перевірка з керівником | Повторити розрахунок за журналом вимірювань. Якщо повнота нижча за погоджений поріг, зафіксувати обмеження висновку про перевагу методу. |
| Статус | Заплановано. Після проведення експерименту додати дату, посилання на дані та фактичний висновок. |

## Форма для власної теми


Редакція, набір, дата перевірки, джерело:

| Код і точне формулювання ПРН | Освітній компонент | Дослідницька дія | Артефакт | Критерій | Строк | Статус |
|---|---|---|---|---|---|---|
| | | | | | | |

Журнал змін: попередня вимога → нова → застосовність → погоджена дія.
