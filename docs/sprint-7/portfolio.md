# Цифрове портфоліо

Рекомендована структура приватного робочого простору:
```
00-governance/
01-concept/
02-literature/
03-models/
04-methods/
05-code/
06-experiments/
07-publications/
08-dissertation/
09-supervision/
10-defense/
```

Кожен артефакт має ID, версію, дату, статус, зв'язок із задачею та режим доступу. Зберігайте журнал змін і резервні копії. Публічний репозиторій — лише для дозволених матеріалів; приватність репозиторію сама по собі не є дозволом на оброблення захищених даних.
