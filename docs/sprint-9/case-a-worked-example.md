# Кейс A. Числовий контрприклад: що саме слід навчати й перевіряти

**Статус:** повністю **вигаданий навчальний розрахунок**, не результати експерименту, не еталон реальної ІАС. Мета — відокремити **допустимість** від **переваг**, а зміну контекстних ваг від наукової новизни.

## 1. Три конфігурації

| Конфігурація | Якість Q ↑ | Час T, умовні одиниці ↓ | Вартість C, умовні одиниці ↓ |
|---|---:|---:|---:|
| A — висока якість | 0.95 | 8 | 7 |
| B — компроміс | 0.82 | 4 | 4 |
| C — швидка й дешева | 0.76 | 2 | 2 |

Лише для цієї вправи вводимо корисність критеріїв v = (Q; 1 − T/10; 1 − C/10). Для емпіричного дослідження масштаб нормування встановлюють **лише на train**, і ці константи не можна добирати за тестом.

- Для A маємо v(A) = (0.95; 0.20; 0.30).
- Для B маємо v(B) = (0.82; 0.60; 0.60).
- Для C маємо v(C) = (0.76; 0.80; 0.80).

## 2. Контекст z1: якість має пріоритет, усі допустимі

Нехай T_max = 8 і C_max = 7. Усі A, B, C допустимі. Контекстні ваги **для ілюстрації**, а не встановлені з експертних даних: w1 = (0.90; 0.05; 0.05).

U_w(A) = 0.90·0.95 + 0.05·0.20 + 0.05·0.30 = **0.880**.

U_w(B) = 0.90·0.82 + 0.05·0.60 + 0.05·0.60 = **0.798**.

U_w(C) = 0.90·0.76 + 0.05·0.80 + 0.05·0.80 = **0.764**.

**Вибір у z1: A**, якщо прийняти саме ці ваги. Це ілюстрація поведінки відомої лінійної скаляризації, не доведення переваги нейромережі.

## 3. Контекст z2: жорсткі межі та зміна переваг

Нехай T_max = 5 та C_max = 5. Тоді F(z2) = {B, C}: конфігурація A **не допустима** незалежно від її бажаності. Для ілюстрації зміни переваг приймемо w2 = (0.30; 0.35; 0.35).

U_w(B) = 0.30·0.82 + 0.35·0.60 + 0.35·0.60 = **0.666**.

U_w(C) = 0.30·0.76 + 0.35·0.80 + 0.35·0.80 = **0.788**.

**Вибір у z2: C**. Якщо залишити фіксовані ваги w1, але правильно фільтрувати F(z2), переможе B (0.798 > 0.764): перехід B → C при зміні пріоритетів дає приклад тестової задачі. Однак контекстна **лінійна** модель уже відтворює цей перехід; просто продемонструвати таку зміну нейромережею недостатньо для заяви новизни.

Якщо зовсім забути про фільтр F(z2) і використовувати w1, система рекомендує A, хоча вона порушує обидві ресурсні межі. Це **помилка постановки**, не аргумент про якість навченої моделі.

## 4. Контекст z3: допустимих альтернатив немає

Нехай T_max = 1 та C_max = 1. Усі конфігурації порушують межі. Тоді F(z3) = ∅. Правильний результат системи — **«допустимого рішення немає»**, незалежно від ваг і функції U.

## 5. Чому цього недостатньо для наукового результату

1. Ваги задані автором прикладу, тому ранги є результатом **визначень**, а не незалежним експертним ефектом.
2. Ми показали лише три ручні розрахунки для однієї таблиці, а не статистичну вибірку.
3. Не навчено Uθ, не перевірено її на інших контекстах, не доведено жодної властивості.
4. B1 — контекстна лінійна модель — вже пояснює рангове переключення: її обов’язково включити в пряме порівняння.
5. Ні попарні порівняння з вагами w1 і w2, ні десятки запусків тих самих трьох альтернатив не слід рахувати як незалежні дослідницькі сценарії.

## 6. Завдання ад’юнкту

**Завдання 1:** без калькулятора відновіть шість сум і допустимі множини.

**Завдання 2:** доберіть інші ваги, за яких у z1 переможе B, та поясніть, чому це не новий метод.

**Завдання 3:** сформулюйте, яким має бути *незалежне* еталонне порівняння для перевірки, чи нелінійна Uθ справді потрібна.

**Завдання 4 — ред-тім:** колега стверджує «мережа навчилася перемикатися між A і C, тому метод є науково новим». Спростуйте висновок за допомогою B1 та статей L05/L06/L08.

**Критерій завершення:** усі розрахунки правильні, а висновок розділяє математичну допустимість, зміну пріоритетів та емпірично доведену перевагу.
